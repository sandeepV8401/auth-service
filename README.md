# Auth Service (Backend Focused)

A modular authentication and authorization service built using a **Monolith Architecture** with **MVC + Service Layer pattern**. This project is designed to demonstrate strong backend engineering practices, clean code structure, and scalable design.

## 🚀 Core Features

- User Registration & Login
- Role-Based Authorization (RBAC)
- Secure Password Handling (Bcrypt Hash Password)
- Token-Based Authentication (JWT)
- Centralized Error Handling
- Layered Architecture (Controller → Service → Model)

## 🚀 Advanced Features

- Refresh Token mechanism (Access + Refresh flow)
- Secure HTTP-only cookies support
- Request Validation (Zod)
- Helmet & Security Headers
- CORS configuration
- Postman Collection

## 🧠 Tech Stack

- Node.js / Express
- MongoDB (Mongoose)
- JWT Authentication
- MVC + Service Layer Pattern

## 🧱 Architecture Highlights

- Clear separation of concerns using Controller & Service layers
- Reusable and testable business logic
- Centralized error handling with consistent API responses
- Scalable and maintainable folder structure

## 🎯 Purpose

This project is built to **showcase backend development skills**, including:

- System design fundamentals
- Code organization & maintainability
- Authentication & authorization workflows

## 🖥️ Frontend (Minimal)

A basic frontend is included only for:

- Login / Register pages
- Demonstrating role-based access
